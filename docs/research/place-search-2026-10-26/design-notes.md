# Design direction
Frontend-design skill applied from the local Claude plugin marketplace.

Palette: Manotu cobalt #0047AB, ink #0B1B3A, pale blue #E3ECFA, white #FFFFFF, coral #FF6B4A, green #17664D for verified outcomes.
Type: Avenir Next with system sans fallbacks for reading; Georgia for the opening editorial headline only. Official outlined wordmark, embedded in the report.
Layout: left-aligned reading column, wide diagram breaks, compact sticky navigation; hero pairs a direct problem statement with a schematic station map. Mobile stacks naturally. Print expands disclosures and hides controls.

    wordmark                  date / print
    headline + conclusion     SVG station illustration
    section navigation
    live evidence table
    diagnosis / current pipeline
    spatial enrichment / proposed flow
    rollout + acceptance + linked evidence

Review: avoid a generic dashboard of metrics. The distinctive element is the station-to-locality illustration; use tables for evidence and diagrams for architecture. No invented performance metrics, no external assets or tracking, no live API calls from the report. Interactivity switches explanatory search scenarios, explicitly labelled as proposed behavior, not a working search demo.
